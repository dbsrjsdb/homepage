# Voronoi Playground

Voronoi Playground is a dependency-free static Canvas tool for moving sites, adding points, and viewing a rasterized nearest-site diagram with palette and edge controls.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- The diagram uses a 4-pixel raster for responsive local rendering.
- Sites are held in memory and can be exported as a PNG.
