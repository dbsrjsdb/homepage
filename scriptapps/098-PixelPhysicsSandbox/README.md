# Pixel Physics Sandbox

Pixel Physics Sandbox is a dependency-free static cellular simulation for painting sand, water, fire, and walls into a grid and watching each material follow simple movement rules.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- The world uses a 120×80 cell grid and updates locally with material-specific rules.
- Materials are held in memory and are not uploaded or persisted.
