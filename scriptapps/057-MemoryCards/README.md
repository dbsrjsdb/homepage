# MemoryCards

MemoryCards is a dependency-free static matching game with generated symbols, animated card flips, easy/medium/hard boards, move and timer tracking, and locally stored best moves.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Choose from 8, 12, or 16 cards; each board is shuffled locally.
- A brief mismatch delay prevents accidental double selection while the cards flip back.
