# ImageCropper

A static, browser-only utility for cropping images with a movable crop frame
and aspect-ratio presets.

## Development

Open `index.html` directly in a browser, or serve this directory with any
static file server. No build step or backend is required. Images are processed
locally and are not uploaded.

## Controls

- Free crop, square, 4:3, 3:4, 16:9, and 9:16 presets
- Drag the crop frame to move it
- Drag a corner handle to resize it
- Export as PNG, JPEG, or WebP
