# Breakout

Breakout is a dependency-free static canvas arcade game with a paddle, bouncing ball, brick collisions, levels, lives, score feedback, keyboard controls, and touch/pointer support.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Use the arrow keys or A/D to move; the on-screen controls and pointer movement support touch devices.
- Clearing a brick awards points and clearing a wall advances the level.
