# Perlin Noise Terrain Map

Perlin Noise Terrain Map is a dependency-free static terrain renderer that turns a seed and layered smooth value noise into a topographic-style landscape with palette and contour controls.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- The renderer uses a fixed 210×140 sample grid and upscales it to the Canvas.
- Terrain is generated locally and can be exported as a PNG.
