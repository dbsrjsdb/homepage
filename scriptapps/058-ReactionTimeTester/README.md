# ReactionTimeTester

ReactionTimeTester is a dependency-free static reaction test. Wait for the panel to turn green, click as quickly as possible, and review recent attempts, best time, and average locally.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- False starts are detected before the signal and do not enter the results list.
- Recent results are limited to eight and stored only in browser storage.
