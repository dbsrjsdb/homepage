# Pathfinding Visualizer

Pathfinding Visualizer is a dependency-free static grid tool for drawing walls and comparing breadth-first search, depth-first search, Dijkstra, and A* exploration.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Start and goal cells are fixed for a consistent comparison.
- Search and animation state remain in memory and are not uploaded.
