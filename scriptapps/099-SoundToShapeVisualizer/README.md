# Sound to Shape Visualizer

Sound to Shape Visualizer is a dependency-free static Web Audio experiment where microphone frequency data deforms a selectable geometric shape in real time.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. Microphone access generally requires HTTPS or localhost.

## Notes

- Microphone data is analyzed in memory and is never recorded or uploaded.
- Permission is requested only after Start microphone is pressed.
