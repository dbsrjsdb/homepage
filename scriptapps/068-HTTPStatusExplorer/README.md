# HTTPStatusExplorer

HTTPStatusExplorer is a dependency-free static reference for common HTTP status codes. Search by code, name, explanation, or use case, then filter by informational, success, redirect, client-error, or server-error category.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- The reference is intentionally compact and focuses on frequently encountered statuses.
- Search and filtering happen locally without network requests.
