# Conway's Game of Life

Conway's Game of Life is a dependency-free static cellular automaton. Draw cells on a responsive grid, run generations at selectable speeds, randomize or clear the population, and load glider, blinker, or pulsar patterns.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- The grid wraps at its edges so cells on one side can interact with the opposite side.
- Pattern generation and simulation remain entirely in the browser.
