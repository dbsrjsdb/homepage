# Color Contrast Checker

Color Contrast Checker is a dependency-free static WCAG contrast calculator with synchronized color pickers, hex fields, live preview, and AA/AAA results for normal and large text.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Contrast uses relative luminance and the WCAG ratio formula.
- Invalid hex input is reported locally instead of being calculated.
