# SQLFormatter

SQLFormatter is a dependency-free static SQL formatter with local keyword highlighting, configurable indentation, sample/clear actions, and copyable formatted output.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- This is a lightweight formatter rather than a full SQL parser; dialect-specific syntax may need manual adjustment.
- Input is not persisted and no query is sent over the network.
