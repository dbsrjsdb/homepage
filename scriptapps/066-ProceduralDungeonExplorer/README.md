# ProceduralDungeonExplorer

ProceduralDungeonExplorer is a dependency-free static mini-adventure. Each run generates a new walkable dungeon, reveals nearby rooms as you move, and places a relic and exit to discover.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Arrow keys/WASD and the on-screen controls move the explorer.
- Reveal map is available for inspecting the generated layout; New dungeon creates a fresh random map.
