# Asteroids

Asteroids is a dependency-free static Canvas game with vector-style ship and asteroid rendering, rotation, thrust, firing, asteroid splitting, waves, lives, scoring, pause, and restart.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Use left/right to rotate, up to thrust, and Space to fire; touch controls are included.
- Rocks wrap around the playfield and split into smaller rocks when hit.
