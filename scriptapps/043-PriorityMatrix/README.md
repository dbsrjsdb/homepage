# PriorityMatrix

PriorityMatrix is a dependency-free static Eisenhower matrix. Add tasks, place them in Do first, Schedule, Delegate, or Drop, and move them with drag-and-drop or an accessible quadrant menu.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Tasks are stored locally under one localStorage key.
- The matrix is a simple four-quadrant urgency/importance model and does not sync across devices.
