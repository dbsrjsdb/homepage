# AspectRatioCalculator

AspectRatioCalculator is a dependency-free static utility for calculating proportional dimensions, simplifying aspect ratios, and comparing common shapes visually. It supports widescreen, classic, square, photo, portrait, and custom ratios.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Enter either dimension to calculate the missing dimension; when both are present, the current ratio is also shown.
- Custom ratios are simplified for display with the greatest-common-divisor calculation.
- The preview shape uses CSS `aspect-ratio` and is illustrative rather than a physical measurement.
