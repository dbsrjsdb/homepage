# Minesweeper

Minesweeper is a dependency-free static puzzle with beginner, intermediate, and custom board presets. It supports revealing, right-click/long-press flagging, a timer, first-click safety, and locally stored best times.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Custom boards accept 5–20 rows and columns, with mine counts automatically capped to leave a safe starting area.
- Click reveals a cell; right-click or a long press flags it.
- Best times remain in browser storage and are separated by preset type.
