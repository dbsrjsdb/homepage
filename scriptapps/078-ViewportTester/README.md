# Viewport Tester

Viewport Tester is a dependency-free static utility for previewing an HTML snippet at common phone, tablet, desktop, or custom viewport dimensions.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- The preview is rendered in a sandboxed iframe with scripts disabled.
- Snippet markup stays in the browser and is never submitted to a service.
