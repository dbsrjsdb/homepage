# Sorting Algorithm Race

Sorting Algorithm Race is a dependency-free static visualizer for comparing bubble, selection, and insertion sort on the same shuffled array with animated bars and operation counts.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- The operation counts are educational comparisons for the current array, not hardware benchmarks.
- Values and race state remain in memory and are not uploaded.
