# Cellular Automata Lab

Cellular Automata Lab is a dependency-free static visualizer for experimenting with elementary Wolfram rules, editable first-row seeds, generation stepping, and animated evolution.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- The canvas displays 120 cells across up to 72 generations.
- Rule state and seeds are held in memory and are not uploaded.
