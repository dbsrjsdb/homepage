# 2048

2048 is a dependency-free static tile-merging game with keyboard, WASD, on-screen, and swipe controls. It includes score tracking, undo, restart, and a locally persisted best score.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Matching tiles merge in the direction of each move; invalid moves do not add a tile.
- The best score is saved in browser storage and can be reset by clearing site data.
