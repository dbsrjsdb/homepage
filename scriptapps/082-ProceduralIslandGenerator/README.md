# Procedural Island Generator

Procedural Island Generator is a dependency-free static Canvas tool for generating stylized seeded island maps with coastline, terrain-detail, and palette controls plus PNG export.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- The same seed and settings produce the same map.
- Terrain is generated locally from layered value noise and a radial island mask.
