# Constellation Maker

Constellation Maker is a dependency-free static Canvas studio for placing stars, connecting them in sequence, naming the shape, scattering a starting arrangement, and exporting a PNG.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Stars and connections are kept in memory and are not uploaded.
- Export uses the browser's Canvas PNG support.
