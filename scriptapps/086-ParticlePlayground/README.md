# Particle Playground

Particle Playground is a dependency-free static Canvas simulation where pointer interaction attracts particles while gravity, palette, and burst controls shape the motion.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Particles are simulated in memory and are not persisted or uploaded.
- The animation starts with a small local burst so the canvas is immediately visible.
