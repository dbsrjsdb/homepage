# TypingSpeedGame

TypingSpeedGame is a dependency-free static typing practice utility with generated prompts, live WPM and accuracy, per-character correct/error visualization, timer feedback, and recent results stored locally.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- The test completes when the prompt is fully typed; WPM uses five characters per word.
- Prompt text, incorrect characters, and recent results stay in the browser.
