# ImageCompressor

A static, browser-only utility for comparing and downloading compressed JPEG
or WebP images.

## Development

Open `index.html` directly in a browser, or serve this directory with any
static file server. No build step or backend is required. Images are processed
locally and are not uploaded.

## Controls

- JPEG or WebP output
- Quality from 10% to 100%
- Before/after file-size comparison and savings estimate
- Drag and drop or browse for images up to 20 MB
