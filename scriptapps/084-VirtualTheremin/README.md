# Virtual Theremin

Virtual Theremin is a dependency-free static Web Audio instrument. Move across the play field to control oscillator pitch and volume, choose a waveform, and adjust the lowest pitch.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Audio is created only after the user presses Start sound or touches the field.
- Pointer position stays local and is not recorded or transmitted.
