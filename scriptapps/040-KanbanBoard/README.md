# KanbanBoard

KanbanBoard is a dependency-free static task board with Backlog, In progress, and Done columns. Add cards, move them with drag-and-drop or buttons, delete them, and keep the board persisted in localStorage.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Board state is stored under a single localStorage key in the current browser.
- Cards can be moved with keyboard-focusable buttons as well as native drag-and-drop.
- No account, network request, or cross-device synchronization is used.
