# Tetris

Tetris is a dependency-free static falling-block game with rotation, line clearing, levels, ghost-piece guidance, hold functionality, keyboard controls, and touch-friendly buttons.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Use arrows to move/rotate/drop, Space for a hard drop, and C to hold the current piece.
- A held piece can be used once per falling piece; the ghost shows where the current piece will land.
