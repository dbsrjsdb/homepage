# AimTrainer

AimTrainer is a dependency-free static target-clicking practice game. It runs 20-target rounds, measures reaction time, tracks hits/misses and accuracy, and stores the best average locally.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Missed clicks count toward accuracy and consume a target from the round.
- Target positions are randomized within a responsive practice field.
