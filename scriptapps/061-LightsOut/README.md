# LightsOut

LightsOut is a dependency-free static logic puzzle with 3×3, 4×4, and 5×5 boards. Toggle a tile and its orthogonal neighbors, request a hint, or apply a minimum-move solution generated locally.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Puzzles are generated by scrambling a solved board, so they are solvable.
- The solver enumerates first-row presses and derives a minimum solution for the selected board size.
