# L-System Plant Generator

L-System Plant Generator is a dependency-free static Canvas tool for growing procedural fern, tree, and bush forms from simple rewriting grammars and turtle-graphics rules.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Iteration, turn angle, preset, and palette settings update the local rendering immediately.
- The canvas is generated in memory and no plant data is uploaded.
