# PixelArtEditor

A static, browser-only pixel art editor with a small grid, palette, pencil,
eraser, fill, eyedropper, and PNG export tools.

Open `index.html` directly or serve this directory with a static file server.
No build step or backend is required. Artwork is kept in the browser.

Grid sizes include 8×8, 16×16, 24×24, and 32×32. Exported pixels are scaled
to a crisp 32 pixels per cell.
