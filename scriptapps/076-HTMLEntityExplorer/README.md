# HTML Entity Explorer

HTML Entity Explorer is a dependency-free static reference for searching common HTML entities and copying named, decimal, or Unicode representations.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- The reference is intentionally curated around common punctuation, symbols, arrows, math, and currency characters.
- Search and copy operations happen locally in the browser.
