# Fractal Explorer

Fractal Explorer is a dependency-free static Canvas tool for rendering zoomable Mandelbrot and Julia sets with iteration, palette, and Julia-constant controls.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Click the canvas to zoom in around a point; double-click to zoom out.
- Rendering and PNG export happen locally in the browser.
