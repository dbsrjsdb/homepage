# ImageResizer

A static, browser-only utility for resizing images by dimensions or percentage.

## Development

Open `index.html` directly in a browser, or serve this directory with any
static file server. No build step or backend is required. Images are processed
locally and are not uploaded.

## Controls

- Resize by exact width and height, optionally preserving aspect ratio
- Resize by percentage from 1% to 1000%
- Export as PNG, JPEG, or WebP
- Drag and drop or browse for images up to 20 MB
