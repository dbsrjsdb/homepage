# Generative Art Playground

Generative Art Playground is a dependency-free static Canvas experiment with seeded artwork, adjustable complexity and radial symmetry, palette choices, and PNG export.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- The same seed and settings produce the same composition.
- Artwork is generated locally and never uploaded.
