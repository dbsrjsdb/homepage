# OneLinePuzzle

OneLinePuzzle is a dependency-free static connect-the-nodes game. Drag through every node exactly once, choose among three generated layouts, request a hint, and track completed puzzles locally.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Each layout has a defined one-line route; wrong nodes do not break the current line.
- Pointer dragging works with mouse, pen, and touch input, and nodes expose labels for assistive technology.
