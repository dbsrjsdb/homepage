# Snake

Snake is a dependency-free static arcade game with keyboard and on-screen controls, increasing speed, score tracking, and a locally persisted top-five high-score list.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Arrow keys and WASD control the snake; the on-screen direction pad supports touch devices.
- The game speeds up as fruit is collected and stores only scores in local browser storage.
- High scores can be cleared from the interface.
