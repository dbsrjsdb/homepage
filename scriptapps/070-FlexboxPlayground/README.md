# FlexboxPlayground

FlexboxPlayground is a dependency-free static editor for flex direction, wrapping, justification, alignment, gap, and item count. It renders a live preview and generates copyable CSS locally.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- The preview and CSS block update as controls change.
- Clipboard permissions vary by browser; the generated CSS remains visible if copying is unavailable.
