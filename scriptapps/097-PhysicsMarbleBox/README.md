# Physics Marble Box

Physics Marble Box is a dependency-free static Canvas sandbox for dropping colliding marbles into a box, tuning gravity/bounce/friction, and dragging obstacles through their path.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Marbles and obstacle state stay in memory and are not uploaded.
- The simulation uses simple circle/rectangle collision handling for an approachable visual model.
