# Fourier Drawing Visualizer

Fourier Drawing Visualizer is a dependency-free static Canvas experiment for sketching a path and reconstructing it with rotating epicycles calculated from a local discrete Fourier transform.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Use Load sample to see a flower-shaped signal without drawing first.
- Path points and Fourier coefficients live only in memory.
