# Double Pendulum Simulator

Double Pendulum Simulator is a dependency-free static Canvas experiment for exploring chaotic motion with adjustable starting angles, gravity, trails, pause, and reset controls.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static file server. No build step or backend is required.

## Notes

- Motion uses a standard two-arm pendulum model integrated locally in the browser.
- The simulation state is not persisted or uploaded.
